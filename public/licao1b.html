Language at Work

💡 Grammar Tip

In English, when we need to talk about the existence of something we can say there is / there are.

In Lancaster, there is one Church. There are streets.
There isn't a Hotel. There aren't Towers in Lancaster.

💡 Grammar Tip
❓ There is / There are
Usamos There is e There are para falar sobre a existência de coisas num lugar (Haver / Existir).
THERE IS (Singular)
"There is a Station nearby."
THERE ARE (Plural)
"There are Churches in London."
NEGATIVE
"There isn't a bank." / "There aren't Towers."
