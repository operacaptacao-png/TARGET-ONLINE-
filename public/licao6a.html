WOULD LIKE (Convites e Pedidos)

1. Convites Formais e Corteses:

Use Would you like to + verb para convidar:
• Would you like to have dinner tonight? (Gostaria de jantar hoje à noite?)
• Respostas: Yes, I'd love to! / I'd like that very much!

2. Pedidos em Restaurantes:

Use I would like / I'd like em vez de "I want":
• I'd like the Italian pasta, please.
• We would like a table for two.

3. Would like vs. Like:

• Do you like wine? = Você gosta de vinho em geral?
• Would you like some wine? = Você gostaria de um vinho agora? (Oferta/Convite).
